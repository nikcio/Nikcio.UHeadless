# Commit Messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/) style:

```
type(scope): description
```

## Types

| Type | Use |
|------|-----|
| `feat` | New feature |
| `fix` | Bug fix |
| `chore` | Maintenance, deps, release |
| `ci` | CI/CD changes |
| `test` | Test changes |

## Scopes

Common scopes: `release`, `docs`, `deps`. Omit the scope when the change doesn't fit one.
